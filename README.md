# Monkey Run Starter Kit

## For the Engine Room (Programmers)
- **Task 1:** Look at `entities.py`. Can you make the Monkey die when energy reaches 0?
- **Task 2:** Implement collision detection so when the Player touches an `Item`, they gain energy or a diamond.

## For the Level Architects (Designers)
- Create a map in **Tiled** that is 800x600 pixels.
- Use the "Object Layer" to decide where the Monkey starts.

## For the Sprite Artists (Artists)
- Your character sprites should be roughly 40x40 pixels.
- Export your animations as transparent .png files and put them in the `/assets` folder.
